# CWTS Management System (Tkinter)

Desktop app for CWTS activity reporting and monitoring: time in/out, reports with photo proof, review and approval, attendance, evaluations, announcements and feedback.

**Run:** `python main.py` (Python 3.9+; Tkinter comes with Python).
**Optional:** `pip install qrcode[pil]` for the QR Code button.
**Tests:** `python -m unittest discover tests`

Start with **WORK_PLAN.md**: IDE advice, project map, every function explained, and a phased plan for learning and changing the code.
